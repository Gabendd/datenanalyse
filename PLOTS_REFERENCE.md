## Format Recommendations

| Use Case | Format | Why |
|----------|--------|-----|
| PowerPoint / Keynote | PNG | Fast loading, instant display |
| Word / PDF reports | PDF | Crisp scalable graphics, smaller files |
| Web pages | PNG | Best browser compatibility |
| Print publications | PDF | Professional quality, no degradation |
| Social media | PNG | Standard format, good compression |

## Technical Specifications

- **PNG:** 300 DPI (publication quality), white background
- **PDF:** Vector format (infinitely scalable), white background
- **Dimensions:** Optimized for both screen (16:9) and print (A4/letter)
